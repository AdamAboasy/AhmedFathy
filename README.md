# نظام المتابعة — أكاديمية أحمد فتحي 🎓

نظام متكامل لمتابعة **الطلبة والكورسات**: الحضور والغياب، الامتحانات والدرجات، الاشتراكات والمدفوعات، التنبيهات، والتقارير المطبوعة والمصدَّرة.

> ⚡ الملف كله **HTML + CSS + JavaScript في ملف واحد** (`index.html`) — يشتغل من غير سيرفر ولا تثبيت أي حاجة.
> البيانات محفوظة في المتصفح (localStorage) مع إمكانية **المزامنة السحابية عبر Firebase** لفتح نفس البيانات من أي جهاز.

## ✨ المميزات

### 🏠 لوحة التحكم
- إحصائيات فورية: عدد الطلبة النشطين، نسبة الحضور، تحصيل الشهر، إجمالي المتأخرات.
- رسوم بيانية (Canvas بدون أي مكتبات خارجية): التحصيل خلال 6 شهور، توزيع الطلبة، الحضور اليومي.
- التنبيهات العاجلة وأحدث الدفعات وقائمة الأكثر انتظامًا.

### 👥 الطلبة
- إضافة/تعديل/حذف، كود تلقائي لكل طالب، بيانات الطالب وولي الأمر.
- اشتراك **شهري** (تاريخ انتهاء) أو **باقة حصص** (عدد الحصص المستهلك يُحسب تلقائيًا من الحضور).
- فلترة بالمجموعة/المستوى/الحالة + ترتيب بالاسم أو النسبة أو المتأخرات + بحث فوري.
- ملف الطالب الكامل: نسبة الحضور، تقويم حضور الشهر، الدرجات، المدفوعات، الملاحظات.

### 🗂️ المجموعات
- أيام الحصة، الميعاد، المستوى، سعر الاشتراك، عدد الطلبة، متوسط الحضور، تحصيل المجموعة.

### ✅ الحضور والغياب
- تسجيل سريع بأربع حالات: حاضر / متأخر / غائب / بعذر + ملاحظة الحصة.
- زر «الكل حاضر»، عدّاد مباشر، وحفظ بضغطة (أو `Ctrl + S`).
- بعد الحفظ: تنبيه واتساب جاهز لأولياء أمور الغائبين.
- كشف حضور الشهر كامل (طلبة × أيام) مع النسب وإمكانية الطباعة.

### 🏆 الامتحانات والدرجات
- إنشاء امتحان (الاسم، المجموعة، التاريخ، الدرجة النهائية).
- إدخال الدرجات بحفظ تلقائي، متوسط وأعلى درجة ونسبة النجاح، ترتيب الطلبة، تصدير وطباعة النتائج.

### 💰 الاشتراكات والمدفوعات
- تسجيل الدفعات (نقدي / تحويل / محفظة) مع تحديد «عن شهر» واكتشاف المتأخرات تلقائيًا.
- **إيصال دفع قابل للطباعة** وإرسال تأكيد واتساب لولي الأمر.
- تجديد الاشتراك لعدة شهور بضغطة واحدة (مع تسجيل الدفعات).
- كشف بالمتأخرات ومتوسط التحصيل وتنبيه الاشتراكات القريبة من الانتهاء.

### 🔔 التنبيهات
- اشتراكات منتهية أو على وشك الانتهاء، متأخرات مالية، غياب متكرر، حصص باقية قليلة، طلبة بدون مجموعة.
- أزرار سريعة للتجديد أو التحصيل أو إرسال واتساب.

### 📊 التقارير
- 6 تقارير جاهزة: الحضور، بيانات الطلبة، التحصيل، المتأخرات، نتائج الامتحانات، وملخص المركز.
- تصدير CSV (يفتح مباشرة في Excel) أو طباعة منسّقة بترويسة المركز.

### 🌙 أخرى
- وضع ليلي/نهاري، تصميم متوافق مع الموبايل والتابلت، نسخ احتياطي واستيراد JSON، بيانات تجريبية للتجربة.

## ☁️ الربط بـ Firebase (المزامنة بين الأجهزة)

1. افتح [console.firebase.google.com](https://console.firebase.google.com) وأنشئ مشروعًا جديدًا.
2. من `Build → Firestore Database` اضغط **Create database**.
3. من `Project settings → Your apps → Web` أنشئ تطبيق ويب وانسخ قيم `firebaseConfig`.
4. من داخل النظام: **الإعدادات → قاعدة البيانات السحابية** الصق القيم + اكتب **كود المركز** (أي كلمة سرية تختارها).
5. اضغط **اتصال** — وبكده أي جهاز يدخل بنفس «كود المركز» هيشوف نفس البيانات لحظيًا.
6. بعد الاتصال استخدم **«رفع كل البيانات»** لرفع بياناتك الحالية، أو **«تنزيل من السحابة»** لجلب بيانات موجودة.

قواعد Firestore المقترحة:

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /centers/{code}/{document=**} {
      allow read, write: if true;
    }
  }
}
```

> ⚠️ **ملاحظة أمنية:** القاعدة السابقة مفتوحة لأي شخص يعرف «كود المركز»، فهي مناسبة للاستخدام السريع/الخاص. للحماية الكاملة استخدم Firebase Auth وفعّل قواعد مبنية على `request.auth`. واختَر كودًا طويلًا وغير متوقع.

## 💾 البيانات والنسخ الاحتياطي

- كل البيانات محفوظة في **localStorage** بمفتاح `af_tracker_v1` (جلسة محلية لكل متصفح).
- من **الإعدادات → نسخ احتياطي** يمكنك: تصدير نسخة JSON، استيراد نسخة، تصدير كل البيانات CSV، أو حذف كل البيانات.
- اعمل نسخة احتياطية دورية (مرة كل فترة) خصوصًا قبل تحديث المتصفح أو تغيير الجهاز.

## 🛠️ التقنيات

بدون أي مكتبات أو أدوات بناء — HTML + CSS + JavaScript خالص:
- الرسم البياني بـ **Canvas API** مباشرة.
- الأيقونات **SVG** مدمجة داخل الملف (بدون أيقونات خارجية).
- الخط `Cairo` من Google Fonts (لو النت مقطوع، الخطوط البديلة تشتغل عادي).
- Firebase (App + Firestore) تُحمَّل عند الحاجة فقط من CDN الرسمي عند تفعيل المزامنة.
