# منصة "المستر" — أحمد فتحي 🎓

منصة لمتابعة الطلاب والحصص والامتحانات، بلغة **HTML / CSS / JavaScript** فقط — بدون أي مكتبات أو أدوات بناء (لا React، لا npm، لا خطوة compile).
التطبيق **PWA** يشتغل من المتصفح، ويُثبَّت على الموبايل/الكمبيوتر كتطبيق، ويعمل **أوفلاين** بعد أول زيارة.

> الواجهة كلها من ملف واحد: `index.html` (HTML + CSS + JS جوّاه)، والألوان كلها مستخرجة من **لوجو المستر** (الأصفر الذهبي `#fac518` + الأسود `rgb(8,8,8)`)، واللوجو نفسه مستخدم زي ما هو **بدون أي تعديل على الصورة**.

### 🖼️ اللوجو
- صورة المنصة الأساسية في ملف **`logo.png`** (ولو مش موجودة، بيرجع تلقائيًا لـ `logo.jpg`، ولو الاتنين مش موجودين بيعرض شعار بديل).
- الصورة بتظهر **جنب اسم "أحمد فتحي"** في القايمة الجانبية، وفي الإعدادات، وفي **هيدر كل التقارير المطبوعة/PDF**.
- **بدون أي تعديل على الصورة**: الملف بيتعرض زي ما هو بالظبط (أي تغيير للأبعاد في العرض هو قص/تحجيم للعرض فقط بـ `object-fit` ومش بيلمس الملف).
- من *الإعدادات ← لوجو المنصة* تقدر **تغيّر الصورة** وتختار صورة من جهازك (بتُخزَّن في `localStorage` كما هي بدون تعديل)، أو **تستعيد الصورة الأصلية** بضغطة.
- الصورة المرفوعة بتغيّر كمان **أيقونة التاب**، وبتتحفظ جوه **النسخة الاحتياطية (JSON)** فبتنتقل معاك لأي متصفح أو جهاز تاني عند الاستيراد.
- مجلد `icons/` فيه نسخ **مشتقّة** من اللوجو بمقاسات أيقونات التطبيق (192/512/maskable/apple-touch/favicon) — مطلوبة تقنيًا لأيقونة الـ PWA فقط.

## 📱 تثبيت التطبيق (PWA)

1. افتح الرابط في المتصفح (لازم `https://` أو `http://localhost` — ميزة التثبيت لا تعمل على `file://`).
2. **أندرويد / Chrome:** هيظهر زرار "تثبيت التطبيق" جوه المنصة، أو من قائمة المتصفح ⋮ ← *تثبيت التطبيق / إضافة إلى الشاشة الرئيسية*.
3. **آيفون / Safari:** زر المشاركة ↗ ← *إضافة إلى الشاشة الرئيسية*.
4. **كمبيوتر:** أيقونة التثبيت ⊕ في شريط العنوان.

بعد التثبيت هتلاقي أيقونة المنصة على الشاشة، وتفتح ملء الشاشة بدون شريط المتصفح، وتشتغل من غير إنترنت.
من الإعدادات ← *التطبيق PWA*: زرار **تثبيت** وزرار **تحديث النسخة** (يمسح الكاش القديم ويجيب آخر نسخة).

## ✨ المميزات

### 👥 الطلاب
- إضافة/تعديل/حذف طالب، وبحث، وفلترة **حسب المرحلة** والدور والمجموعة.
- كل طالب ليه: **المرحلة**، **نظام الدراسة**، **نوع الطالب** (جديد/مستمر/ضيف…)، **المستوى**، **الحصة/المجموعة**، **طريقة الدفع** (بالحصة / بالشهر)، ورقم واتساب وملاحظات.
- **نظام الدراسة ذكي حسب المرحلة:** "الثاني الثانوي" ← عام / بكالوريا / أزهر، وأي مرحلة تانية ← عام / أزهر فقط.
- الطالب ينفع يكون **بدون مجموعة** (حصة خاصة أو لسه متوزّعش).

### 🗓️ المجموعات والحصص
- إنشاء حصة: الاسم، المرحلة، المستوى، **اليوم + من الساعة كم ل الساعة كم**، طريقة الدفع (بالحصص / بالشهر).
- **منع تعارض الحصص:** النظام يرفض حفظ أي حصتين وقتهم متقابل في نفس اليوم، ويبيّن لك الحصة المتعارضة قبل الحفظ.
- توزيع الطلاب على الحصة عند الإنشاء أو بعدها، وإضافة/شيل أي طالب في أي وقت.

### ✅ الحضور والغياب
- تسجيل **حضور كل مجموعة لوحدها** مع التاريخ.
- 4 حالات: حاضر / متأخر / غائب / بعذر + ملاحظة للحصة.
- "تحضير الكل" بضغطة، ومصفوفة حضور لكل الطلاب، وإجماليات ونسبة حضور لكل طالب.
- تنبيه بالطلاب اللي غابوا كتير، وتقارير حضور قابلة للطباعة.

### 📝 الامتحانات والدرجات
- إنشاء امتحان وتحديد **المرحلة** و**المجموعة** بتاعتها والدرجة النهائية.
- رصد الدرجات لكل طالب، ومتوسط / أعلى / أدنى درجة، وترتيب الطلاب.

### 🖨️ التقارير و PDF
- تقارير جاهزة: متابعة طالب، كشف حضور، كشف طلاب، نتائج امتحانات، تقرير عام.
- **طباعة / حفظ PDF** لأي تقرير أو كشف (كشف الحضور للحصة، درجات الامتحان، بيانات طالب، كل الطلاب، المجموعات).
- تصدير Excel (CSV) + نسخة احتياطية **JSON** واستيرادها.

### 🌙 الوضع الليلي
- وضع ليلي/نهاري كامل، وبيفتكر اختيارك.

### ⚠️ ملاحظة مقصودة
- **كل ما يتعلق بالفلوس مشيل بالكامل:** لا تحصيل، لا مبالغ، لا متأخرات، لا إيصالات، ولا تقارير مالية.
- اللي باقي هو **حالة الدفع كتتبّع فقط**: الطالب "دفع / لم يدفع"، وطريقة الدفع "بالحصة / بالشهر".

## 💾 تخزين البيانات والمزامنة بين الأجهزة

### 1) على الجهاز (الأساسي)
كل البيانات محفوظة في متصفح الجهاز نفسه (`localStorage` — المفتاح `mostar_platform_v2`). مفيش حساب ولا تسجيل دخول، والمنصة شغالة حتى بدون إنترنت.

### 2) المزامنة السحابية (Firebase) — شغالة تلقائيًا
**الإعدادات جاهزة جوه الكود** (Project ID `ahmedfathy-95c10` + API Key + كود المنصة)، يعني **مش مطلوب تكتب أي حاجة**.

- أول ما تفتح المنصة بتتصل بالسحابة لوحدها.
- **الجهاز اللي فيه البيانات** → بيتم رفعها تلقائيًا أول مرة (أو اضغط "رفع الكل").
- **أي جهاز تاني** → البيانات بتنزل عنده تلقائيًا (أو اضغط "تنزيل").
- كل تعديل بيترفع لوحده، وكل 20 ثانية + كل مرة ترجع للصفحة بيتم فحص لو فيه تحديث أحدث من جهاز تاني وبينزل تلقائي.
- **اللوجو كمان بيتزامن** — تغيّره مرة وتلاقيه على كل الأجهزة.

#### خطوة واحدة مطلوبة منك مرة واحدة بس (تفعيل قاعدة البيانات) ⚠️
لو ظهرت رسالة **"قاعدة بيانات Firestore لسه مش متعملة"**، اعمل الآتي مرة واحدة:

1. افتح [Firebase Console ← Firestore](https://console.firebase.google.com/project/ahmedfathy-95c10/firestore).
2. اضغط **Create database** ← اختار **Start in test mode** ← Next ← **Enable**.
3. روح تبويب **Rules** ← من المنصة اضغط زر **"قواعد الحماية (انسخها)"** ← الصق ← **Publish**.
4. ارجع للمنصة ← الإعدادات ← **اختبار الاتصال** — لازم يقولك كله تمام ✅، وبعدها **رفع الكل** على الجهاز اللي فيه البيانات و**تنزيل** على أي جهاز تاني.

> لو ظهر أي خطأ، زر **اختبار الاتصال** بيقولك السبب بالعربي والحل خطوة بخطوة (قاعدة مش متعملة / قواعد الحماية / الخدمة مش مفعّلة / مفيش إنترنت).
> ملاحظة أمان (اختياري): كل البيانات بتتخزن تحت اسم **"كود المنصة"** — لو حبيت تخليه خاص بيك غيّره لأي كلمة سرية من الإعدادات، وأي جهاز يكتب نفس الكود يشوف نفس البيانات.

### 3) النسخة الاحتياطية
من الإعدادات: **نسخة احتياطية (JSON)** (بتشمل اللوجو) و**استيراد نسخة** — و**تصدير Excel/CSV**.

## 🗂️ ملفات المشروع

```
index.html               التطبيق كامل (واجهة + ستايل + كود + أيقونات SVG + اللوجو)
manifest.webmanifest     إعدادات التطبيق (الاسم، الأيقونات، ألوان، التثبيت)
sw.js                    Service Worker: تشغيل أوفلاين + تحديث النسخ
icons/                   أيقونات التطبيق (192 / 512 / maskable / apple-touch / favicon)
logo.png                 لوجو أحمد فتحي — زي ما هو بدون تعديل (والبديل logo.jpg)
```

> **عن قيد "HTML/CSS/JS فقط":** الكود كله HTML/CSS/JS ولا يوجد أي مكتبة أو إطار عمل. لكن تشغيل **PWA** (تثبيت + أوفلاين + أيقونة) بيحتاج 3 ملفات مساندة إلزامية من المتصفح: `manifest.webmanifest` و`sw.js` وأيقونات `icons/`.
> مينفعش يتحطوا جوّه `index.html` (المتصفح بيطلبهم كملفات حقيقية من نفس الدومين؛ ملفات `blob:`/`data:` مرفوضة للـ Service Worker).
> لو رفعت `index.html` لوحده، المنصة هتشتغل عادي — بس من غير تثبيت ولا أوفلاين.

## 🚀 النشر على GitHub Pages

1. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / مجلد `/ (root)` ← Save.
2. استنى دقيقة، والرابط هيبقى: `https://<username>.github.io/AhmedFathy/`.
3. افتح الرابط على الموبايل وثبّت التطبيق من زرار "تثبيت".

> أوفلاين: بعد أول فتح، الـ Service Worker بيخزّن الملفات، والتطبيق يفتح من غير نت.
